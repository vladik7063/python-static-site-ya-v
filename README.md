# Отчёт о пошаговом создании и публикации статического сайта на MkDocs + GitHub Pages

> Репозиторий: https://github.com/vladik7063/python-static-site-ya-v  
> Опубликованный сайт: https://vladik7063.github.io/python-static-site-ya-v

---

## Шаг 1. Создание репозитория на GitHub
1. Авторизовался в аккаунте GitHub.
2. Нажал кнопку «New repository».
3. Заполнил имя: `python-static-site-ya-v`.
4. Оставил репозиторий публичным, без README и лицензии.
5. Нажал «Create repository».

---

## Шаг 2. Клонирование репозитория локально
1. Открыл терминал PowerShell в рабочей папке.
2. Выполнил команду:
   ```bash
   git clone https://github.com/vladik7063/python-static-site-ya-v.git
3. Перешёл в папку проекта: cd python-static-site-ya-v

---

## Шаг 3. Создание виртуального окружения
1. Внутри папки проекта выполнил:python -m venv venv
2. Убедился, что появилась папка venv.

---

## Шаг 4. Активация окружения
1. Для Windows в PowerShell: .\venv\Scripts\activate
2. В командной строке появился префикс (venv), что подтвердило активацию.

---

## Шаг 5. Установка MkDocs
1. В активированном окружении выполнил: pip install mkdocs
2. Проверил версию: mkdocs --version
3. Выполнил: mkdocs new
   В результате появились:
  ⋅⋅*mkdocs.yml — конфигурационный файл
  ⋅⋅*docs/index.md — стартовая страница

---

## Шаг 6. Локальный просмотр
1. Запустил сервер: mkdocs serve
2. Открыл браузер по адресу http://127.0.0.1:8000 и убедился, что страница отображается корректно.

## Шаг 7. Настройка автоматического деплоя (CI/CD)

Для автоматической сборки и публикации сайта был настроен GitHub Actions.

В репозитории создан workflow `.github/workflows/deploy.yml`, который:
- запускается при push в ветку `main`
- устанавливает Python и MkDocs
- выполняет сборку сайта командой `mkdocs build`
- публикует результат на GitHub Pages

Таким образом, процесс деплоя сайта полностью автоматизирован.

## Шаг 8. Публикация сайта

В настройках репозитория GitHub Pages в качестве источника выбран `GitHub Actions`.

После успешного выполнения workflow сайт становится доступен по адресу:  
https://vladik7063.github.io/python-static-site-ya-v

## Исследовательская часть

### Использование отечественных CDN

Для ускорения доставки статического контента в России могут использоваться:
- Яндекс Cloud CDN
- VK Cloud CDN
- Selectel CDN

CDN позволяют снизить задержки, повысить отказоустойчивость и уменьшить нагрузку на сервер.

### GitVerse как платформа CI/CD

GitVerse предоставляет возможности для хранения репозиториев и настройки CI/CD,
аналогичные GitHub Actions, и может использоваться как альтернатива
в условиях импортозамещения.

### Варианты деплоя статического сайта

Существуют следующие способы деплоя статических сайтов:
- GitHub Pages / GitLab Pages
- Объектные хранилища (S3, Yandex Object Storage) + CDN
- VPS или собственный сервер (Nginx, Caddy)
- Docker + CI/CD пайплайн

Выбор способа зависит от требований к масштабируемости и отказоустойчивости.
